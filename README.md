# Stelios Ch. — Portfolio

A single-page portfolio application built with React, featuring multiple routes, animated page transitions, an interactive particle canvas, and a fully data-driven architecture.

**Live site:** https://SteliosChatzis04.github.io/Portfolio/

---

## Tech Stack

- **React 18** + **React Router 6**
- **Vite** — build tooling
- **CSS** — custom properties, scroll-triggered animations
- **Formspree** — contact & CV request forms
- **GitHub Actions** — automated CI/CD to GitHub Pages

## Deployment

Every push to `master` triggers a GitHub Actions build and deploys to GitHub Pages automatically.
